# Gate Control Center (GCC)

**Self-hosted Gate.io trading, native trading bot monitoring, portfolio analytics, and wallet management.**

Gate Control Center (GCC) brings Gate.io operations into a unified web interface. Originally built to monitor exchange-native trading bots, it has evolved to include supported trading operations, multi-account wallet management, analytics, security, and administrative controls.

> **Project status:** Active development · **Source:** Private / proprietary · **Exchange:** Gate.io

## Features

### Native trading bots
- Monitor and manage supported Gate.io Spot Grid and Infinity Grid bots.
- View bot configuration, status, trading activity, and performance.
- Analyze realized grid earnings and other available performance metrics.

### Portfolio and trading
- Monitor balances and market information.
- Review order books, trading activity, and historical account data.
- Use supported trading operations through the Gate.io API.

### Wallet operations
- View assets and balances for connected Wallet accounts.
- Supported deposit, withdrawal, and internal transfer workflows.
- Multi-account visibility and separation.

### Security and administration
- Authentication and account security features.
- Account-level action permissions and root administrator controls.
- Auditing and safeguards for sensitive operations.

### User interfaces
- **Aurora:** Responsive modern interface.
- **Classic:** Alternative interface.
- **Demo:** A dedicated demonstration experience, separate from live account operations.
